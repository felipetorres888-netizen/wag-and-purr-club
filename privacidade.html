Privacy Policy

Wag & Purr Club Esteira · Last updated: October 8, 2026

What this application is

Wag & Purr Club Esteira is an internal tool used exclusively by the owner of the Wag & Purr Club YouTube channel. It uploads the channel's own videos using the YouTube API Services. It is not offered to the public and has no users other than the channel owner.

What data we access

The application requests permission to upload videos (youtube.upload) and to read basic channel data (youtube.readonly), the latter only to confirm the channel name before each upload. It does not read, collect or store data about viewers, subscribers or any other person.

How data is stored

The authorization granted by the channel owner (a Google access token) is stored only on the channel owner's computer. It is not sent, sold or shared with anyone.

YouTube API Services

This application uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.

How to revoke access

Access can be revoked at any time on the Google Account permissions page: myaccount.google.com/permissions.
